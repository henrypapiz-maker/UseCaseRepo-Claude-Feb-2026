## Top Highlights

### 1. Claude Code Revenue Doubles to $2.5B Run-Rate — Anthropic Valued at $380B
Claude Code's annualized revenue doubled since January 1 to reach $2.5B, while Anthropic's total revenue hit $14B. ### 2. Claude Code Security Shakes Cybersecurity Industry
Anthropic launched Claude Code Security (Feb 20), a reasoning-based vulnerability scanner built on Opus 4.6 that found 500+ previously unknown high-severity vulnerabilities in open-source codebases during internal testing. The announcement wiped billions in market cap from CrowdStrike (-8%), Cloudflare (-8.1%), SailPoint (-9.4%), and Okta (-9.2%). CISOs were caught off guard — most didn't expect reasoning-based scanning this early in 2026.

### 3. Cowork Goes Enterprise-Grade — Plugins, Marketplace, 12 New Connectors
Claude Cowork transitioned from research preview to full enterprise product (Feb 24) with department-specific plugins (HR, finance, design, engineering), a private enterprise marketplace, and 12 new MCP connectors (Google Calendar, Gmail, Drive, DocuSign, FactSet, etc.). Enterprise software stocks continued their slide — ServiceNow (-23%), Salesforce (-22%), Intuit (-33%), Thomson Reuters (-31%) since the Jan 30 announcement. PwC partnered with Anthropic on compliant deployment for regulated industries.

### 4. Figma "Code to Canvas" Creates Bidirectional Design-Code Loop
Figma and Anthropic launched Code to Canvas (Feb 17), enabling developers to push rendered UIs from Claude Code into Figma as fully editable design layers — not screenshots, but actual structured frames. This closes the design-to-code-to-design loop and establishes MCP as the connective tissue between creative and engineering tools.

### 5. GitHub Becomes the "Switzerland" of AI Coding Agents
GitHub's Agent HQ (Feb 4) brings Claude and OpenAI Codex directly into GitHub for all Copilot tiers (Business & Pro access added Feb 26). Google, Cognition, and xAI agents are next. GPT-5.3-Codex launched with 25% faster agentic coding. Microsoft's strategy: owning the platform where developers choose between AI agents matters more than forcing a single AI vendor.

## What Matters Most This Week

The two-week period delivered three inflection points:

**1. Security as a product category.** Claude Code Security represents Anthropic's first move beyond coding productivity into an adjacent, high-value enterprise software category. The cybersecurity stock sell-off signals that the market views reasoning-based vulnerability scanning as a genuine platform threat — not incremental tooling.

**2. Cowork enterprise launch redefines TAM.** With department-specific plugins, private marketplaces, and PwC compliance partnerships, Cowork is no longer a research experiment — it's an enterprise platform play that directly competes with ServiceNow, Salesforce, and vertical SaaS. The 20-33% stock declines across enterprise software peers confirm the market is pricing in disruption risk.

**3. The multi-agent platform war is on.** GitHub's Agent HQ, with Claude and Codex available to all Copilot tiers, signals that the IDE/platform layer is becoming agent-agnostic. The winning strategy is no longer "build the best agent" alone — it's "build the best agent AND be present on every platform where developers work." Anthropic's simultaneous moves on Figma integration, GitHub Agent HQ, and its own VS Code extension suggest it's pursuing both.

The Vercept acquisition (computer-use AI) and Claude Sonnet 4.6's 72.5% OSWorld score hint at the next frontier: agents that don't just write code but operate entire software systems through their UIs.
